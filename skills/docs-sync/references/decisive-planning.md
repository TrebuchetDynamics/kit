# Evidence-driven planning and reconciliation

The executor and local task CLI are removed. Follow
[Plan Handoff](../../shared/PLAN-HANDOFF.md) for complete GitHub issue batches and
[Docs Sync](../SKILL.md) for current document maintenance. Read back issues, native
dependencies and PR/check/review evidence before changing readiness. Preserve
actual ownership, explicit pauses, accepted scope and unresolved live qualification.

Existing local task records, attempts, worktrees and recovery state are read-only
migration evidence. Do not recreate, mutate or prune that store as a second queue.
Reconcile still-required work against open and closed issues before publishing;
never invent completion or transfer a historical claim to a new worker.
