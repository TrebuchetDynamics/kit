# Drawing styles

Search for the requested style or choose one from this list. Open only that
row's library and example. Open [core](upstream/lib/core.py) only for a shared
helper the selected library uses. If you need more detail, search the pinned
[upstream protocol](upstream/PROTOCOL.md) for the library class and read only
its matching API notes or troubleshooting section.
