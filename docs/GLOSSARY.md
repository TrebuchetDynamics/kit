# Kit glossary

## Handed back

The existing delivery owner has been given the retained commit, the missing behavior, and how to verify it on the original issue. A handoff is not evidence that work **resumed**: that requires observed pickup or continued work. Do not use **recovered** or **delivered** for a handoff alone.

Source: [ADR 0002 — Hand back incomplete work on the same issue](adr/0002-hand-back-incomplete-work-on-the-same-issue.md).
