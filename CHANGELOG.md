# Change history

Use Git history for past changes. This repository does not keep completed-task reports or a duplicate task archive.

Current behavior and requirements are documented in [the product specification](docs/project.md), [the reference](docs/reference.md) and [the runbooks](docs/installation.md). Unfinished work belongs in GitHub Issues, with Orbi as the delivery successor. The pi-autowork executor and task CLI are retired and unsupported; preserved local records are migration evidence, not an executable backlog.

Source commits, installation and live qualification are distinct; removing historical records proves none of them.
