# Change history

Use Git history for past changes. This repository does not keep completed-task reports or a duplicate task archive.

Current behavior and requirements are documented in [the product specification](docs/project.md), [the reference](docs/reference.md) and [the runbooks](docs/installation.md). Unfinished work belongs in the task store (`autowork tasks`), which the runner creates on demand.

Source commits, installation and live qualification are distinct; removing historical records proves none of them.
